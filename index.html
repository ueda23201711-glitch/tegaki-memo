英文リーダー

🎬 YouTube の動画で読む

🎞 手元の動画と字幕で読む（.webm / .mp4 ＋ .srt）

ダウンロードした動画と、英語の字幕（.srt）を選んでください。日本語の字幕（.srt）も選ぶと、それを訳として使います（翻訳の回数を使いません）。動画はこの端末に保存し、Google ドライブにも送るので、ほかの端末でも見られます。

字幕は、アドレスだけ入れて押せば自動で取ってきます（英語の字幕がある動画）。取れないときの貼り付け方（パソコンが簡単です）：YouTube で動画を開き、説明欄の「…もっと見る」→ いちばん下の「文字起こしを表示」→ 右に出た文字起こしをドラッグで最後まで選んでコピーして、上に貼り付けます（時刻も一緒に）。字幕ファイル（.srt / .vtt）の中身でも大丈夫です。

📚 画像から本を作る（パソコン向け）

Kindle などのページのスクリーンショットをまとめて選ぶと、この端末の中で英文を読み取り（画像はどこにも送りません）、章ごとの英文にして保存します。保存した本は、ほかの端末（iPad 2/3 も）でも読めます。買った本を自分で勉強するためだけに使ってください。

読み取る範囲：下の1枚目の画像の上で、本文の部分をドラッグして囲んでください（ページ上の本の題名の帯や、下のページ番号・ボタンは外す）。本文の文字にかからないよう、まわりに少し余白を残して囲むのがコツです。全部の画像に同じ範囲を使います。見開き（2段）の画面でも、左の段 → 右の段の順に読み取ります。

章の区切りを確かめてください：✓ の付いた行から新しい章になります。押すと付けたり外したりできます（目次の行などは外してください）。

保存した単語・熟語は 📚 メモ単語帳 で学習できます（iPad 2/3 は こちら）。

翻訳の設定（Google Apps Script）

ご自分の Google アカウントで Google 翻訳を使います。手順は案内のとおりに。下のコードを Apps Script に貼り付けて「ウェブアプリ」として公開し、表示されたアドレスを入れてください。

🔖 ブックマークから送る

ウェブの英語の記事を見ているときに、このブックマークを押すと、そのページの本文（文字を選んでいれば選んだ部分）を英文リーダーで開きます。
① 下の「コードをコピー」を押す
② 今見ているこのページをブックマークに追加する（名前は「英文リーダーで読む」など）
③ ブックマークを編集して、アドレス（URL）の欄を全部消し、コピーしたコードを貼り付けて保存
iPad・iPhone の Safari：共有ボタン →「ブックマークを追加」→ あとで「ブックマーク」→「編集」でアドレスを貼り替え。
パソコンの Chrome：☆ でブックマーク → ブックマークを右クリック →「編集」→ URL に貼り付け。

📤 共有ボタンから送る（iPhone・Android）

Android：この英文リーダーをホーム画面に追加（インストール）しておくと、Chrome やニュースアプリの「共有」の送り先に「手書きメモ」が出ます。押すと、その記事を読み込みます（出ないときは、一度アンインストールして入れ直してください）。
iPhone・iPad：「ショートカット」アプリで、共有ボタンに「英文リーダーで読む」を追加します（最初に一度だけ）。
① ショートカットアプリを開き、右上の ＋ を押す
② いちばん上の名前を押して「英文リーダーで読む」にする
③ 下の検索で「URLを開く」を探して追加する
④ 下の「アドレスをコピー」を押し、「URLを開く」の青い「URL」の部分に貼り付ける
⑤ 貼り付けた文字のすぐ後ろで、キーボードの上の「ショートカットの入力」を選ぶ（「…#ru=」の後ろに「ショートカットの入力」が付いた形）
⑥ 右上の ⓘ（または名前の横の ⌄ →「詳細」）で「共有シートに表示」をオンにして「完了」
使うとき：Safari などで記事を開き、共有ボタン →（いちばん下の）「英文リーダーで読む」。英文リーダーは Safari で開くので、Safari の英文リーダーにも合言葉を入れておいてください（「合言葉」の QR をカメラで読むと簡単です）。

AIの声（Google Gemini・無料枠）

「通しで聞く」の「声」で AI の声を選ぶと、より自然な読み上げになります（ネットが必要。iPad 2/3 は端末の声のほうが確実です）。
① aistudio.google.com を開き「Get API key」→「APIキーを作成」で鍵をコピー
② 上のコードを Apps Script に貼り替えて保存
③ Apps Script の左の ⚙「プロジェクトの設定」→ 下の「スクリプト プロパティを追加」→ プロパティ GEMINI_KEY、値に鍵 →「保存」
④「デプロイ」→「デプロイを管理」→ ✏ → バージョン「新バージョン」→「デプロイ」（アドレスは変わりません）
⑤ 下の「AIの声をテスト」（許可を聞かれたら「詳細」→「安全ではないページに移動」→「許可」）
作った声は、ご自分の Google ドライブの「英文リーダーの声（AI）」フォルダに保存され、どの端末からでも回数を使わずに聞き直せます。
「📎 ファイル共有」で送ったファイルは、ドライブの「手書きメモ・英文リーダーの共有ファイル」フォルダに入ります（このコードが必要です）。

AIの声（Microsoft Azure・無料枠 毎月50万文字）
